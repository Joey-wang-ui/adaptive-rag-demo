# 嘉惠内部业务助手 · Windows 桌面版

完整解压 JiahuiAssistant-Windows-x64.zip，双击 JiahuiAssistant.exe 或 START.cmd。包内已包含 Python 运行环境、项目依赖和构建后的网页，不需要安装 Python、Node 或执行部署命令。请保留整个目录（包括 _internal）。

首次在窗口中创建管理员账号（密码至少12位），填写 DeepSeek Key 后进入工作台；也可稍后连接模型。以后直接打开软件并登录。关闭窗口会停止该软件启动的本地服务，资料不会清空。

Windows 10/11 64位。如本机缺少微软 WebView2，软件会提示运行包内经过签名校验的微软安装组件，只需安装一次；此步骤需要网络和Windows安装授权。不要删除包内的微软组件安装文件。

左下角“资料与模型设置”：管理员可导入 UTF-8 产品 CSV 或文字版 PDF，下载模板，设置或更换 DeepSeek Key。PDF只作为带页码的参考资料，资料有效性待确认；产品 CSV 默认草稿，核实后勾选现行目录才用于正常产品查询。重复导入可安全重试，资料更新前自动备份。扫描版 PDF 需要先完成 OCR 核对。

勾选安全保存时，DeepSeek Key只保存在当前Windows账号的凭据管理器；不写入普通JSON、日志或账号数据库。没有真实可用模型时，界面会明确标注原文节选或降级状态。API调用需要联网和供应商可用额度。价格、库存、订单尚未连接管家婆，第一版不执行真实业务写操作。

资料、账号与日志默认位于 %LOCALAPPDATA%\JiahuiAssistant，独立于软件解压目录。升级时关闭旧软件，解压新版后运行即可复用该用户目录。备份请包含整个用户目录。若需使用原项目已有资料，可先关闭软件，备份后将原 data/jiahui 内容放入该用户目录的 data 子目录；不要覆盖已有账号/资料，冲突时先由管理员核对。

错误日志：%LOCALAPPDATA%\JiahuiAssistant\logs\desktop-server.log。界面的模型连接状态以实际探测为准，不把配置了Key等同于已经连接成功。

## v1.1.3 升级后登录检查

升级不会更换原账号密码。请关闭旧版后再运行新版，继续使用首次创建的账号；`admin` 只是可能的账号名，没有默认密码。登录页可显示密码便于核对，密码中的空格会原样保留。

如果升级后原密码登录失败，先关闭软件，双击包内 **检查账号和资料目录.cmd**。它在本机显示当前资料目录、已有账号及停用状态；如果与旧版不一致，选择原来包含 `auth.sqlite3` 的资料文件夹，然后重新打开软件，用**原账号和原密码**登录。此操作不重置密码、不移动业务数据；切换配置前自动备份。默认资料目录为 `%LOCALAPPDATA%\JiahuiAssistant\data`，不是新版软件的解压目录。自定义相对路径现固定从用户数据主目录解析，避免随解压位置改变。

仅在确需重设密码时，先关闭软件，再双击 **恢复账号.cmd**，从已有账号中选择，隐藏输入两次新密码（至少12位）。此操作先备份账号数据库，再仅更新该账号的密码并撤销其旧登录；原岗位权限、其他账号、资料和DeepSeek Key均保留，停用账号不会被启用。该入口只在本机运行，没有网页免登录重置接口。不要删除 `auth.sqlite3` 或通过覆盖资料目录来解决登录问题。备份位于所选资料目录的 `backups` 文件夹。

源码维护者也可在本机交互终端使用 `python -m app.jiahui.auth reset-password --username 原账号 --data-dir 原资料目录`，密码隐藏输入；不要把密码或Key发送给他人。

## v1.1.2 资料导入与复用修复

PDF来源版本可留空，默认标注“来源版本待确认”；文字页导入后直接可查，标准六列表格会另外录入可查询参考产品目录，不再与现行产品数混淆。导入诊断会列明成功页、跳过页与表格异常。

升级首次启动会检查旧版已保存PDF并补建缺失产品目录，保留账号、Key、原件及人工确认状态；以后直接复用。也可在资料管理点击“检查并修复已导入目录”。重复导入不会增加同一PDF记录，原件和版本更新前有备份。

新增一份【AI整理】嘉惠助手操作指引（非公司制度），仅说明软件导入、核实与保存步骤。它与原始PDF分开列出来源，不能作为产品事实、公司制度、价格或库存依据。连接DeepSeek时会发送问题与相关授权资料片段到其API。

## v1.1.4 产品查询与连接状态问答

支持“帮我查下蛋液有哪些”等口语问法，目录列表和比较按表格呈现名称、编号、规格、储存条件；未提供的字段保留为空缺提示，不补造产品资料。蛋液检索可以找到目录中明确写出的蛋黄液、蛋白和全蛋液等名称，不会据此推测用途、保质期或储温。来源集中放在回答下方“查看来源”中，展开可核对PDF页码、行号及版本。

“模型连接了吗”“查一下模型链接”等问题读取最近一次真实模型探测结果，不检索产品或操作手册。连接检查通过与当前每次调用成功不同；需要复查时在“资料与模型设置”重新测试。对话模型和语义向量模型独立配置，未配置真实Embedding时仍会说明哈希/关键词降级。软件操作指引仅参与软件使用相关问题的检索，不能作为产品资料依据。

## v1.1.5 常用问答与通用对话

产品连续追问会核对当前账号可访问的会话和目录：先查具体商品，再问“那保质期呢”“这个怎么储存”，会沿用已明确的商品。前一问有多个商品/规格时仍需选择，不擅自猜测。查询单个字段只回答该字段，空字段明确提示需要确认。

写通知、翻译、解释概念等问题直接调用已配置的模型API，标注“通用参考（未使用嘉惠业务资料）”，不附伪造产品来源。写作模板不代表嘉惠现行制度；产品、制度及实时业务事实继续先核对资料或只读接口。模型未连接或调用失败时明确提示，不拼接无关手册。API调用按供应商规则计费。

源码复核：在已安装依赖的本机运行 `python scripts/check_jiahui_common_questions.py --pdf "你的嘉惠2026产品目录.pdf"`，会在临时目录导入资料并启动回环服务，测试33条固定常用问题。结果保存到 `logs/common-question-results.json`（含原回答，不应公开上传）。这是当前2026目录的固定验收集，不是任意目录的完整测评，也不是DeepSeek真实模型幻觉率。

## v1.1.6 按次联网搜索

输入框左下角点击“联网搜索”，输入完整的公开搜索词并发送；开关默认关闭，发送后自动关闭，仅作用于本次提问。可使用 `site:`、`-site:` 和引号等搜索语法，例如“site:厂家官网域名 产品公告”。搜索词最多128个Unicode字符，过长时请自行缩短。

联网复用现有DeepSeek Key，不另存密钥。聊天连接验证通过不代表账户具备搜索权限；搜索返回鉴权失败、未开通、额度不足、超时或限流时会如实提示，不会把模型记忆当成联网结果。可能产生搜索和模型API费用：每次最多一次搜索，返回最多5条；生成总结和依据检查通常分别调用一次模型；模型HTTP失败重试沿用已有配置，可能增加请求次数。此次仅接入 Search，按接口的摘要和长摘要回答，`need_content=false`；未接入Fetch，不声称已抓取或阅读全文。

搜索请求只包含当前搜索词、条数和正文开关，不附带内部知识、历史对话、客户资料、定位IP或额外原始问题字段。涉及价格、库存、订单和写操作时仍走原只读业务边界，不用互联网替代管家婆；涉及内部信息的问题会提示关闭联网。联网按钮遵守服务端的知识资料访问权限。

联网回答标明“公开网页参考”、查询时间和来源链接，未知发布时间不猜测。总结先核对来源编号，再进行依据检查；未通过检查或没有可用生成模型时只展示标明身份的搜索摘要。公开网页不自动导入正式嘉惠知识库，也不作为嘉惠现行制度、在售目录、成交价或实时库存依据。

Search接口参数依据用户提供的[官方接口文档](https://api-docs.deepseek.com/zh-cn/api/search)。本云环境无用户真实Key，已运行模拟接口契约、失败分支及真实本机HTTP/浏览器测试，未宣称已验证供应商收费服务的实际可用性或真实模型幻觉率；实际搜索权限以本机请求结果为准。

## v1.1.7 软件内编辑技能模板

管理员登录后，打开左下角“资料与模型设置 → 技能模板”。有产品查询、业务知识问答、通用对话、联网搜索四类，均已接入嘉惠版实际流程，独立于原电商技能文件。

1. 选择技能。产品查询可改列表开头（只支持 `{count}` 占位符）、多规格澄清提示、列表条数、列项与详情布局；其他三类可改模型表达要求，例如“先写结论，再分三点解释”；业务知识还可选择要点、编号步骤、分段原文或原文与来源表格。模板不能代替产品目录或公司制度，不要录入产品事实、账号密码或Key。
2. 点击“预览生效规则”查看草稿与固定边界，不调用模型。“测试问答”使用草稿走真实路由和当前账号权限，不保存草稿、不写入正式会话或知识库；问题应与所选技能相符。知识问答仍要求可核验原文，不因风格修改而自由补造事实。测试可能调用收费模型API；联网测试还必须单独勾选允许联网。
3. 点击“保存并生效”，下次提问就读取新模板，无需重启或重新打包。正在回答的问题继续使用开始时读取的版本；修改后先用新问题验证。退出未保存的编辑会提醒；“重新加载”可放弃草稿。
4. 调整不满意，可“载入此技能默认草稿”后保存，或在历史版本中恢复整组模板。恢复前会备份当前已保存版本；多窗口发生版本冲突时不会覆盖，需重新加载后再编辑。

模板位于所选资料目录的 `skills/templates.json`，版本备份位于 `skills/history`，不在软件解压目录里。备份请包含整个资料目录；升级不会覆盖已保存模板。文件格式异常时停止使用异常模板，管理员页面会提示恢复；非法占位符、未知工具字段和无效列项会被拒绝。保存采用版本校验、互斥锁和原子替换，先备份再更新。

权限、来源与版本校验、只读ERP边界、写操作禁用、搜索是否按次开启，以及API密钥处理不属于可编辑模板。新增工具/API、改变安全边界或增加界面能力仍需要软件更新。本版不开放任意代码、Jinja表达式或工具定义编辑。
