# 问答路径与验收边界

业务事实先找证据。产品问题查询当前账号可访问的产品记录；业务知识在同一权限范围内进行混合检索和重排序，然后由模型选择可核验原文，校验出处和逐字依据后展示。查询不到或原文未给出的字段明确提示需要确认。模型给出无依据的保质期、储温、食品功效、价格或库存时不作为业务回答。

| 问题 | 执行路径 | 回答依据 |
| --- | --- | --- |
| 产品、编号、规格、比较 | 权限过滤 → 目录检索 → 澄清或字段/表格回答 | 已导入记录与对应来源 |
| 嘉惠业务知识 | 权限过滤 → 混合检索 → 重排序 → 模型选择依据 → 引用校验 | 授权的现行/参考知识；版本分别标明 |
| 模型连接状态 | 读取最近一次真实探测结果 | 运行状态；不检索手册 |
| 普通知识、翻译、写作 | 调用已配置模型API | 标注通用参考，不伪造嘉惠引用 |
| 价格、库存、订单 | 只读适配接口 | 尚未接入时明确说明，不使用历史报价代替实时数据 |

通用问答不把旧业务回答重新发送到模型；只复用已标注为通用参考的对话。产品追问只继承当前账号仍有权限访问、且上一问已明确到单条的记录，多个商品/规格时不能猜测。软件操作指引不混作产品依据。

## 可重复检查

在源码依赖环境运行：

```bash
python -m pytest tests -q
python scripts/check_jiahui_common_questions.py --pdf "你的嘉惠2026产品目录.pdf"
```

固定目录集覆盖33个常用问法：蛋液/奶油/面粉及品牌列表、前导零编号、重复编号澄清、对比、资料概况、模型连接的多种问法、价格库存订单未接入、拒绝写操作、未知编号与两次连续追问。目录只导入临时目录，正式资料不受影响。结果含原回答，默认在被Git忽略的 `logs/common-question-results.json` 中，不应公开上传业务回答。

防幻觉测试使用可控模型输出，主动注入不存在的36个月保质期、零下18度储温、任意替代性、500箱库存、100元成交价和治疗功效，检查未通过依据校验的内容不会出现在业务答案中；另测错引用、混合真假引用、无效JSON、旧版本、缺失资料及权限。它验证拦截规则，不代表真实DeepSeek输出的统计幻觉率。

本云环境没有用户的真实DeepSeek Key。本轮通用API分支用可控模型验证调用及资料边界；真实目录测试在显式离线状态运行。不能把这些测试通过写成“真实模型幻觉率为0”。真实模型需在安全配置有效Key后，另用独立人工标注问题集统计无依据事实句数/事实句总数，并分别报告检索命中、拒答与引用正确率。不要将未生成回答的离线查询记作真实生成样本。
