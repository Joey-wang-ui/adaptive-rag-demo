# 嘉惠产品资料导入

在仓库根目录运行。产品数据独立放在 `data/jiahui/products.json`；不读原电商演示资料、不接入其订单或商品。空目录无需种子数据即可启动。Web首次使用前需按嘉惠启动说明初始化账号。

1. 复制本目录的 `产品目录模板.csv`，使用 UTF-8 编码保存。Excel 导入 CSV 时将“商品编号”列指定为文本，保留 `06401`、`009` 等前导零。
2. 每条记录填写稳定的“内部记录ID”和“名称”。同一编号可以对应多条记录，不能把编号作为内部记录ID。别名以半角或全角分号分隔。
3. 来源位置填写 `PDF第5页，原表第34行`、章节或工作表行号。导入还会自动附加 CSV 物理行号，并保留原始 CSV 的 SHA-256 命名副本。
4. 默认按草稿导入（不会作为现行问答依据）：

   ```bash
   python -m app.jiahui.import_catalog --csv "你的产品目录.csv" --data-dir data/jiahui
   ```

5. 经业务核对为当前适用资料后，明确导入为现行：

   ```bash
   python -m app.jiahui.import_catalog --csv "你的产品目录.csv" --data-dir data/jiahui --status current
   ```

Windows 使用当前虚拟环境的解释器：`.venv\Scripts\python.exe -m app.jiahui.import_catalog --csv "你的产品目录.csv" --data-dir data/jiahui --status current`。请使用启动器实际创建的虚拟环境路径；不要向其他环境导入。

更新同一记录同一版本会替换该版本，写入前自动备份。新增版本时保留内部记录ID、修改版本号；新版本设为 current 后，旧版本自动设为 historical。未到“有效日期”的资料不作为现行问答依据；若未来版本不应立即取代旧版，先以 draft 导入，生效时再明确切换为 current。删除旧记录不会通过“本次CSV不含该行”隐式执行；停用资料请显式导入 historical 状态。重复导入相同内容不改变 JSON，不产生重复条目。

CSV 可有“状态”与“访问范围”附加列，分别覆盖 CLI 默认值。状态仅允许 `draft`、`current`、`historical`。范围默认 `products`；可以设为 `procurement` 等自定义范围，对应账号获准的 scopes。每条记录一个范围。`*` 是账号管理权限，不是产品的公开范围。更改权限后需要重新加载索引的模块应重启服务；产品目录查询按最新文件加载。

原件和副本放 `data/jiahui/sources/`，导入备份在 `data/jiahui/backups/`。导入器只将来源路径作为引用元信息，不打开任意路径；拒绝绝对路径、URL及 `..` 路径。现有业务数据更新前请同时备份整个 `data/jiahui`，包括产品、来源、认证和其他持久化资料。导入采用独占锁，若异常中断留下 `.catalog-import.lock`，先确认没有导入进程，再手动移除锁，不能盲目重试覆盖。

## 中文字段

| 字段 | 填写规则 |
|---|---|
| 内部记录ID | 必填，稳定独立键；同一记录不同版本共用ID；不同商品不能只用相同编号做ID。 |
| 商品编号 | 字符串，保留前导零、字母、连字符、星号及空格；允许重复。 |
| 名称 | 必填，原文商品名，不补写功效或适用性。 |
| 品牌 | 经确认的品牌；不能将供应商系列标题自动当品牌。 |
| 品类 | 经确认的业务分类，缺失留空。 |
| 别名 | 业务确认的别名，分号分隔，不自动制造俗称。 |
| 规格 | 原始规格，多个规格选项请拆分成独立内部记录或明确保留需澄清状态。 |
| 包装单位 | 有明确依据的包装单位，不与计价单位混同。 |
| 计价单位 | 经确认的实际计价单位，缺失留空。 |
| 已确认的单位换算 | 填写JSON数组字符串，例如 `[{"from":"箱","to":"盒","factor":"12"}]`；系数必须是明确的有限正数（字符串），不能填算式，不根据品类猜测。留空表示没有已确认换算。 |
| 储存条件 | 原文描述；“冷藏”不自动扩展为具体温度范围。 |
| 保质期 | 有明确来源的期限；不从品类推断。 |
| 产地 | 原文地区；“进口”不推断为国家。 |
| 来源文件 | 相对文件名，不含绝对路径、URL或路径穿越。缺省保留本次CSV名。 |
| 来源位置 | PDF页码、章节、原表行号；另自动记录CSV行号。 |
| 版本 | 可追溯的资料版本；文件名不证明当前有效。 |
| 有效日期 | 明确生效日期 YYYY-MM-DD；不得以文件创建日替代。 |
| 状态 | 可选；draft/current/historical，默认draft。 |
| 访问范围 | 可选；默认products，自定义范围须与账号scope一致。 |

## 演示隔离与原始PDF

`demo-only/演示格式_非真实产品.csv` 仅演示格式，明确使用虚构名称、相同编号和不同规格；禁止导入正式嘉惠目录。测试应指定临时 `--data-dir`，不要混入业务资料。

用户提供的《杭州嘉惠目录表2026年4月修改(2)(1).pdf》共22页。只留存原件并不代表产品已导入，更不表示当前有效。原表存在同编号不同商品（1564、1672、1702、1703）、一行多规格、缺少单位、储存条件冲突及左右并列清单，不能无人工核对地按行转成确认SKU。保质期、现行价格、库存、订单及食品替代适用性尚无依据。未提供字段留空。目录提到的“冻转鲜附页”不在22页文件内。
